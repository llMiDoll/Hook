# Hook — GitHub Pages build

This build is ready to deploy as a static GitHub Pages site.

## Deploy

1. Create a GitHub repository.
2. Upload **all files and folders in this directory** to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Open the generated GitHub Pages URL.
